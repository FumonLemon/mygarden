## 标题层级

从这一节开始,从上到下分别是 H2、H3、H4。H1 留给文章标题,不在正文里重复。

### H3 小节标题

正文段落。中文排版下,段落之间应当有足够的行距,长段落在窄屏上不应挤压变形。这里写够长度来测试段落的换行与两端对齐——测试用文本通常故意写得比实际内容长,好让渲染的问题暴露得早一些。英文与数字混排也不该破坏基线,例如 `Hello, Box 2026`。

#### H4 小节标题

更小的层级,用于测试标题字号的递减是否平滑。

## 代码

### 行内代码

在终端里执行 `hugo server -D`,然后在浏览器打开 `http://localhost:1313`。

### Python

```python
def box(content: str) -> str:
    """把内容装进盒子。"""
    lid = "─" * 20
    return f"{lid}\n│ {content}\n{lid}"

print(box("hello, cardboard"))
```

### 图文混排:左浮动

{{< float-image "/logo.png" "left" >}}

浮动图片环绕排版:文字应该从图片的右侧流过,窄屏(手机)上则应自动退化为普通段落流,避免图压文字。

段落内容需要足够长才能看出环绕效果。这里继续写一些没有实际意义的填充文字,用来检验多行文本围绕浮动图片时的行宽与行高是否正常,以及图片是否真的浮在文字左侧而不是把段落挤开。
